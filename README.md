# 🕉️ Kriya

> *You have the right to perform actions, but never to the fruits of action* — Bhagavad Gita 2.47

**Kriya** is a mindful productivity app that turns your daily tasks into a spiritual journey. Every task you complete unlocks a verse of the **Bhagavad Gita**, blending focused productivity with timeless wisdom — one shloka at a time.

## ✨ Features

- ✅ **Tasks & Quick Add** — Capture tasks effortlessly. Separate multiple tasks with a full stop to add them all in one go.
- 🎯 **Focus Sessions** — Long-press any task to enter Focus Mode and get things done with intention.
- 📿 **Bhagavad Gita Journey** — Each completed task unlocks the next shloka of the Gita. Track your progress across all 18 chapters and 701 verses.
- 📚 **Sacred Scriptures** — A growing library including the Nachiketa Upanishad, Ashtavakra Gita, and more, unlocked as you progress.
- 🔖 **Bookmarks** — Save the shlokas that resonate with you.
- 📅 **Calendar & Weekly Insights** — See active days, completed tasks, focus sessions, and focus time at a glance.
- 🔔 **Daily Reminders** — A gentle nudge to plan your day, on your schedule.
- 🌗 **Dark / Light Mode** — Beautiful in both.
- 📤 **Share Shlokas** — Share wisdom with beautifully rendered quote cards.
- 🔒 **Offline First** — All your data stays on your device, stored locally with SQLite. No accounts, no tracking.

## 🛠️ Tech Stack

- [Expo](https://expo.dev) / [React Native](https://reactnative.dev)
- [Expo Router](https://docs.expo.dev/router/introduction/) for file-based navigation
- [Zustand](https://zustand.docs.pmnd.rs) for state management
- [Expo SQLite](https://docs.expo.dev/versions/latest/sdk/sqlite/) for local persistence
- [Reanimated](https://docs.swmansion.com/react-native-reanimated/) & [Skia](https://shopify.github.io/react-native-skia/) for fluid UI

## 🚀 Getting Started

```sh
# Install dependencies
npm install

# Start the dev server
npm start
```

Then press `i` for iOS or `a` for Android, or run:

```sh
npm run ios
npm run android
```
